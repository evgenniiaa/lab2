## Домашнее задание к работе 2 (вар.32)
### Условие задачи
Возраст Коли – Х лет, а возраст Миши – Y лет. Найти их средний возраст, а также
определить, на сколько отличается возраст каждого мальчика от среднего значения.
### 1. Алгоритм и блок схема
#### Алгоритм
1. Начало
2. Ввести исходные данные:
X - возраст Коли.
Y - возраст Миши.
3. Вычислить средний возраст:
avg = (X + Y) / 2.0
4. Вычислить отклонение возраста Коли от среднего:
dX = X - avg
5. Вычислить отклонение возраста Миши от среднего:
dY = Y - avg
6. Вывести результаты расчётов:
avg - средний возраст.
dX - на сколько возраст Коли отличается от среднего.
dY - на сколько возраст Миши отличается от среднего.
7. Конец

### 2. Реализация программы
```
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

int main() {
    setlocale(LC_CTYPE, "RUS");
    int X, Y;
    double avg, dX, dY;

    printf("Введите возраст Коли X: ");
    scanf("%d", &X);
    printf("Введите возраст Миши Y: ");
    scanf("%d", &Y);

    avg = (X + Y) / 2.0;
    dX = X - avg;
    dY = Y - avg;

    printf("Средний возраст: %.2lf\n", avg);
    printf("Отклонение возраста Коли: %.2lf\n", dX);
    printf("Отклонение возраста Миши: %.2lf\n", dY);

    return 0;
}
```
